# piksel-onizleme

GitHub sayfalarımızdaki bütün piksel görselleri (banner'lar, butonlar, paneller, depo başlıkları, avatarlar) tek sayfada gösteren küçük bir önizleme. `index.html` dosyasını tarayıcıda açman yeterli; görseller doğrudan depolardan geliyor, yani her zaman güncel hallerini görüyorsun.
